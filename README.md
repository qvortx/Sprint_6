Финальный проект 6-го спринта: Автоматизация UI для сервиса "Яндекс.Самокат"

Проект содержит набор автоматизированных UI-тестов для веб-приложения Яндекс.Самокат https://qa-scooter.praktikum-services.ru/ с применением паттерна проектирования Page Object Model (POM) и генерацией отчетов Allure.

## Стек технологий
* Python 3
* Pytest
* Selenium WebDriver (Firefox)
* Allure Report

## Архитектура и структура проекта
* `locators/` - директория с классами локаторов веб-элементов, распределенных по страницам:
  * `main_page_locators.py` - локаторы главной страницы (кнопки заказа, логотипы, аккордеон вопросов и ответов).
  * `order_page_locators.py` - локаторы двух экранов формы заказа ("Для кого самокат", "Про аренду") и модальных окон подтверждения.
* `pages/` - директория с Page Objects, инкапсулирующими логику взаимодействия с элементами интерфейса:
  * `base_page.py` - базовый класс с методами явных ожиданий (WebDriverWait), скролла, кликов, получения текста и переключения между вкладками.
  * `main_page.py` - методы взаимодействия с главной страницей и аккордеоном "Вопросы о важном".
  * `order_page.py` - методы поэтапного заполнения полей формы оформления заказа и подтверждения.
* `tests/` - директория с тестами, сгруппированными по функциональности:
  * `test_accordion.py` - параметризованный тест выпадающего списка "Вопросы о важном" (проверка 8 пар вопрос-ответ).
  * `test_order.py` - сквозные позитивные сценарии оформления заказа через верхнюю и нижнюю точки входа с двумя наборами данных.
  * `test_logo_redirects.py` - проверка редиректов по клику на логотип "Самокат" (на главную) и "Яндекс" (на Дзен в новой вкладке).
* `data.py` - тестовые данные (URL-адреса сервиса, словарь с текстами ответов аккордеона, наборы входных данных для заказа).
* `conftest.py` - фикстура Pytest `driver` для инициализации и завершения сессии браузера Firefox.
* `allure_results/` - директория со сгенерированными артефактами Allure-отчета.
* `.gitignore` - исключение кэша (`__pycache__`, `.pytest_cache`), виртуального окружения и локальных отчетов.
* `requirements.txt` - список внешних библиотек и зависимостей проекта.
